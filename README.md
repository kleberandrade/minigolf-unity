Unity mini-golf physics example exploring the Magnus effect.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Scenes/SampleScene.unity](https://github.com/kleberandrade/minigolf-unity/blob/master/Assets/Scenes/SampleScene.unity).

## Recorded requirements

- Recorded Unity Editor: **2019.2.1f1** in [ProjectSettings/ProjectVersion.txt](https://github.com/kleberandrade/minigolf-unity/blob/master/ProjectSettings/ProjectVersion.txt).
